# Documentation

## Purpose
Project documentation and planning documents. Contains design documents, architecture decisions, and implementation plans for major features.

## Subdirectories
- `plans/` - Implementation planning documents (see docs/plans/AGENTS.md)

## Key Files
- `plans/2025-01-18-batch-generation-design.md` - Design document for CLI batch generation feature

## For AI Agents

### Document Naming Convention
- Planning docs: `YYYY-MM-DD-<feature-name>-design.md`
- Architecture docs: `architecture-<component>.md`
- API docs: `api-<endpoint-group>.md`

### Working in This Directory

- **Adding documentation**: Create markdown files following naming convention
- **Design documents**: Should include problem statement, proposed solution, alternatives considered
- **Planning documents**: Include timeline, milestones, and success criteria

## Dependencies
